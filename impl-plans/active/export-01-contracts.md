## Intent and context

Pin every contract the wave-2 plans share, add all third-party dependencies
(the only plan allowed to touch lockfiles), and prove the dependencies load
in Bun and inside the `bun build --compile` sidecar before anyone builds on
them. Read `impl-plans/active/export-00-overview.md` "Rules for every
worker" first.

  work (plans 02-09).
- Do not change `packages/core/src/svg-export.ts`.
- Do not change behavior of `packages/ui-solid/src/raster-export.ts`

### 2. `packages/core/src/export-formats.ts`

Imitate the doc-comment density of `packages/core/src/svg-export.ts` and the
error style of `packages/ui-solid/src/raster-export.ts:rasterDimensions`.

Pinned exports:

```ts
export type ExportScope = "page" | "selection" | "auto";
export type ExportFormat = "png" | "svg" | "pdf";
export const DEFAULT_EXPORT_PADDING = 16;
export const DEFAULT_EXPORT_BACKGROUND = "#f6f4ee";
export const RASTER_SCALES = [0.5, 0.75, 1, 1.5, 2, 3, 4] as const;
export const MAX_PDF_PAGE_POINTS = 14400;
export function parseExportBackground(value: string): string | null; // lower-cased #rrggbb, null when invalid
export function svgRasterDimensions(svg: string): { width: number; height: number };
export function rasterDimensions(width: number, height: number, scale: number): { width: number; height: number };
export function pdfPageSize(svg: string): { width: number; height: number }; // throws above MAX_PDF_PAGE_POINTS
export function exportScopeSvg(editor: Editor, scope: ExportScope, options: { background: string | null; pageId?: PageId }): string | null;
export function exportFileName(base: string, scope: "page" | "selection", format: ExportFormat, scale?: number): string;
```

- `svgRasterDimensions` and `rasterDimensions`: move the bodies verbatim
  from `packages/ui-solid/src/raster-export.ts` (same messages, same 8192 /
  32 MP limits, `Math.ceil`).
- `parseExportBackground`: accepts exactly `/^#[0-9a-f]{6}$/i`, returns it
  lower-cased; anything else returns `null`. It does not mean "transparent";
  callers decide.
- `pdfPageSize`: width/height from `svgRasterDimensions`; throws
  `PDF export is limited to 14400 points per side. Export a selection or use SVG or PNG.`
  when either side exceeds `MAX_PDF_PAGE_POINTS`.
- `exportScopeSvg` (design 3.2), using the public `Editor` methods
  `exportPageSvg` / `exportSelectionSvg` / `exportArtboardSvg` and
  `renderPageSvg` for an explicit `pageId`:
  - `page`: `renderPageSvg(editor.store, editor.registry, pageId ??
    editor.currentPageId, { padding: DEFAULT_EXPORT_PADDING, background })`
    (`Editor.registry` is public, `packages/core/src/editor.ts:272`). Do not
    call `editor.setCurrentPage` (it mutates editor state) and do not add
    Editor API.
  - `selection`: exactly one selected element whose type is `frame` ->
    `editor.exportArtboardSvg(id, { background })`; otherwise
    `editor.exportSelectionSvg({ padding: DEFAULT_EXPORT_PADDING, background })`.
  - `auto`: must reproduce today's `apps/desktop/src/App.tsx:exportSvg`
    exactly: a single selected frame -> `exportArtboardSvg(id)` with no
    background; a non-empty selection -> `exportSelectionSvg({ background })`;
    otherwise `exportPageSvg({ background })` (default padding).
- `exportFileName`: `<base>.<ext>` for the page, `<base>-selection.<ext>`
  for the selection; for PNG with `scale !== 1`, insert `@<scale>x` before
  `.png` (for example `doc-selection@2x.png`). `base` is used as given (the
  desktop sanitizes it with `exportBaseName`).

### 3. `packages/core/src/export-font-usage.ts`

Pinned exports (types are the contract for plans 02, 03, 04, 05, 06, 09):

```ts
export interface FontFaceInfo { readonly source: string; readonly index: number; readonly postscriptName: string; readonly families: readonly string[]; readonly weight: number; readonly italic: boolean }
export interface FontCatalogue { readonly platform: "macos" | "linux" | "windows"; readonly faces: readonly FontFaceInfo[]; readFace(face: FontFaceInfo): Promise<Uint8Array> }
export interface FontUsage { readonly stack: string; readonly bold: boolean; readonly italic: boolean; readonly codePoints: ReadonlySet<number> }
export interface ResolvedFace { readonly key: string; readonly info: FontFaceInfo; readonly data: Uint8Array }
export interface FontChoice { readonly stack: string; readonly bold: boolean; readonly italic: boolean; readonly faceKey: string }
export interface ResolvedExportFonts { readonly faces: readonly ResolvedFace[]; readonly choices: readonly FontChoice[]; readonly genericFamilies: { readonly sansSerif?: string; readonly serif?: string; readonly monospace?: string }; readonly warnings: readonly string[] }
export function normalizeFontStack(value: string): string;
export function isBoldWeight(value: string | undefined): boolean;
export function scanFontUsage(svg: string): readonly FontUsage[];
```

- `normalizeFontStack`: split on commas, trim, strip one pair of matching
  single or double quotes per family, collapse inner whitespace, join with
  `", "`. Both the usage scan and the PDF font lookup use it, so the same
  stack always produces the same key.
- `isBoldWeight`: `"bold"`, `"bolder"` or a number >= 600 -> true.
- `scanFontUsage`: a tokenizer for svg-export output only (attributes are
  double-quoted, text is escaped by `escapeXml`, no comments/CDATA/PI). Walk
  start/end/self-closing tags with a stack of inherited `font-family`,
  `font-weight`, `font-style` (root `<svg>` sets the theme family). Collect
  the decoded text content (decode `&amp; &lt; &gt; &quot; &#39;` and
  numeric entities) of `<text>`/`<tspan>` into the code-point set of the
  effective (normalized stack, bold, italic). Ignore whitespace-only text
  between tags and text outside `<text>`. Output sorted by stack, then bold,
  then italic (deterministic).
- Re-export both modules from `packages/core/src/index.ts` with the same
  `export { ... } from` style used there.

## Tests to add

`export-formats.test.ts` (build documents like
`packages/core/src/svg-export.test.ts` does):
- page with two shapes, background `#f6f4ee` -> equals
  `editor.exportPageSvg({ background: "#f6f4ee" })`.
- `pageId` of a non-current page -> renders that page's elements, not the
  current page's.
- selection of one frame -> equals `exportArtboardSvg(id, { background })`;
  selection of two shapes -> equals `exportSelectionSvg({ padding: 16, background })`.

- empty page -> `null`.
- hidden element and element inside a hidden frame -> their `data-id` is absent from the output.
