## Intent

BPMN 2.0 XML interchange in `@nodetto/io`, dependency-free:
- a small non-validating XML parser and a deterministic serializer
- `importBpmnXml`: `.bpmn` -> one nodetto document with one `bpmn` page,
  keeping XML ids, semantics, lanes, flows, labels, positions, and
  preserving unsupported and foreign content with warnings
- `exportBpmnXml`: a `bpmn` page -> spec-valid BPMN 2.0 XML that bpmn.io
  opens, byte-deterministic
- `bpmnSemanticProjection` for the lossless contract
- the canonical JSONL of the complete fixture, generated by the importer

## Non-goals

- No dependency (no XML library, no bpmn-moddle).
- No dependency on `@nodetto/core` (io depends only on `@nodetto/ir`); the
  route resolver is injected through `options.routeOf`.
- No lint (bpmn-05), no CLI (bpmn-12), no desktop (bpmn-15).
- Choreography, conversation and transaction are preserved as raw XML
  only, never modelled.

## File-level changes

### bpmn/xml.ts (design 5.1)

- `parseXml(text): XmlElement` with `XmlElement = { name; prefix?; local;
  ns?: string; attributes: readonly XmlAttribute[]; children: readonly
  XmlNode[] }`, `XmlAttribute = { name; prefix?; local; ns?; value }`,
  `XmlNode = XmlElement | { kind: "text"; text: string }`.
- Supports: XML declaration, elements, attributes, namespace resolution
  (`xmlns`, `xmlns:p`, scoped), text, CDATA (merged into text), comments
  and PIs dropped, the five predefined entities, decimal and hex character
  references.
- Errors (`BpmnParseError` with a line number): any `<!DOCTYPE`, unknown
  entity, mismatched or unclosed tag, duplicate attribute, unbound prefix,
  nesting depth > 512, content after the root.
- `serializeXml(root, options)`: 2-space indent, LF, trailing newline,
  attributes in the order given by the caller (export supplies the fixed
  order, then foreign attributes sorted by qualified name), escaping
  `& < > "` and `\n` as `&#10;` in attributes, `& < >` in text. Elements
  with only text are written inline (`<a>text</a>`); empty elements
  self-close.
- Implement as a single-pass scanner with an explicit stack (no
  recursion-based parsing that could overflow before the depth check).

### bpmn/import.ts (design 5.2)

Implement the mapping table of design 5.2 exactly (collaboration and
processes, lanes, flow nodes, event definitions, gateways, flows, data and
artifacts, DI, missing DI, unsupported constructs, foreign content).
Key rules:
- Root must be `definitions` in the BPMN MODEL namespace, else
  `BpmnParseError`.
- `parent`: innermost lane listing the node in `flowNodeRef`; else the
  enclosing sub-process; else the participant whose process contains it;
  else none.
- Default flow: the source's `default` attribute -> `isDefault: true` on
  that flow.
- DI: only the first `BPMNDiagram` positions the page. `BPMNShape` bounds
  -> visual x/y/width/height; `BPMNLabel` with `dc:Bounds` ->
  `visual.labelBounds`; a `BPMNLabel` without Bounds is accepted and
  ignored (bpmn.io writes empty labels). `isMarkerVisible` ->
  `markerVisible`; `isExpanded` -> sub-process `expanded` / participant
  collapsed. Vertical pools (`isHorizontal="false"`) -> warning, drawn
  horizontally.
- Edge waypoints: interior points (all except first and last) ->
  `routingWaypoints` via `connectorWaypointFromPage(point, fromCentre,
  toCentre)` from `@nodetto/ir` with `routing: "manual"`; no interior points
  -> `routing: "straight"` (a manual route without waypoints carries no
  information); more than `MAX_CONNECTOR_WAYPOINTS` (32) -> keep the first
  32 and warn.
- Missing DI: auto-place shapes in a row below the bounding box of placed
  shapes (100 units apart); flows get default routing; add the id to
  `missingDi` and warn.
- Unsupported constructs (`transaction`, choreography and conversation
  elements, any unmapped semantic element): raw XML (re-serialized with
  `serializeXml`) plus its DI into `page.extensions.bpmnXml.unsupported`
  with a warning naming tag and id. Never drop silently.
- Foreign attributes and children (`extensionElements`, `documentation`,
  non-BPMN namespaces) -> `element.extensions.bpmnXml.{attributes,
  children}`; root-level `message`, `signal`, `error`, `escalation`,
  `dataStore` definitions -> `page.extensions.bpmnXml.rootElements`;
  namespace declarations -> `page.extensions.bpmnXml.namespaces`; XML-only
  ids (`definitionsId`, `targetNamespace`, `collaborationId`, `processId`,
  `laneSetIds`, participant `processRef`) per design 3.4.
- The result must pass `assertValidDocument` (call it before returning).

### bpmn/ids.ts and bpmn/export.ts (design 5.3)

- `bpmnExportId`: NCName check `^[A-Za-z_][A-Za-z0-9._-]*$`; otherwise
  prefix by type (`Activity_`, `Event_`, `Gateway_`, `Flow_`,
  `Participant_`, `Lane_`, `DataObjectReference_`, `DataStoreReference_`,
  `TextAnnotation_`, `Group_`, `Association_`, `DataAssociation_`) and
  replace invalid characters with `_`. Idempotent.
- XML-only ids from extensions when present, else derived
  (`Definitions_<pageId>`, `Collaboration_<pageId>`,
  `Process_<participantId>`, `LaneSet_<parentId>`, `<id>_di`), all through
  the NCName rule.
- Fixed namespaces: bpmn, bpmndi, dc, di, xsi with the standard OMG/W3C
  URIs; preserved foreign namespaces after them sorted by prefix;
  `targetNamespace` default `http://bpmn.io/schema/bpmn`.
- Order exactly as design 5.3 (collaboration with participants then
  message flows; one process per expanded participant in index order with
  laneSet, flow nodes with incoming/outgoing children, data objects,
  sequence flows, artifacts; preserved root and unsupported XML; then
  BPMNDiagram/BPMNPlane with shapes for pools, lanes, nodes in index
  order, then edges). Pool-less nodes on a page with participants -> extra
  unreferenced process plus a warning.
- Waypoints: `options.routeOf(edge)` when it returns points, else manual
  waypoints converted back with `connectorWaypointToPage` plus outline
  docking approximated by box-border intersection toward the neighbour
  point. Round to 2 decimals; print integers without a decimal point.
- Event definitions: XML ids from `definition.id`; `timer` ->
  `timeDate`/`timeDuration`/`timeCycle` with `xsi:type="bpmn:tFormalExpression"`;
  `condition` -> `conditionExpression`; default flow -> source `default`
  attribute.

### bpmn/equivalence.ts (design 5.4)

`bpmnSemanticProjection(document, pageId)`: sorted (by exported id) array
of `{id: bpmnExportId, type, semantic-without-routing-and-without-definition-ids, parent}`;
coordinates and `extensions` excluded.

## Pitfalls

- io must not import `@nodetto/core` (would create a cycle; core
  dev-depends on io).
- Do not drop unknown content silently; every skipped construct produces a
  warning and is stored raw.
- The four fixtures and the four local reference files must import with
  zero warnings.
- `export(import(export(p)))` must equal `export(p)` byte for byte: never
  emit anything depending on Map iteration order of unsorted input.
- `.reference/` must never be committed or copied; `reference.test.ts`
  reads it at test time only and asserts no reference labels or text.
